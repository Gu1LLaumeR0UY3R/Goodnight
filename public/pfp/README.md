# Dossier des Photos de Profil

Ce dossier contient les photos de profil des utilisateurs.

## Format des fichiers
- Format: `user_{id}_{timestamp}.{extension}`
- Extensions autorisées: jpg, jpeg, png, gif, webp
- Taille maximale: 5MB

## Permissions
Les fichiers doivent avoir les permissions appropriées (0644) et le dossier doit être accessible en lecture/écriture par le serveur web.
